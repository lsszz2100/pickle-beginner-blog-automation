# 03. 글의 규격을 정한다

자동 발행이 실패하는 이유는 대개 문장력이 아니라 형식입니다. 글자 수가 매번 다르고, 이미지가 두 장이거나 여덟 장이고, 태그가 일곱 개이거나 열세 개입니다. 사람이 읽으면 큰 문제가 아니지만, 검증하는 입장에서는 매번 예외가 됩니다.

규격은 취향의 문제가 아닙니다. 자동화가 스스로 판단할 수 있게 만드는 장치입니다. "이 글이 발행해도 되는 상태인가"를 예 또는 아니오로 답할 수 있어야, 하루 마흔 편을 돌려도 사람이 전부 읽지 않아도 됩니다.

이 장에서 만드는 것은 A4 한 장짜리 규격표입니다. 표에 적힌 숫자는 앞으로 모든 원고에 적용되고, 그 숫자를 검사하는 스크립트가 03-5에 나옵니다.

| 항목 | 기준 |
| --- | --- |
| 분량 | 공백 포함 3,000~5,000자 |
| 문단 계층 | h1 섹션, h2 소제목, h3 목차 |
| 섹션 수 | 5~7개 |
| 이미지 | 3~7장, 대표이미지 1장 |
| 태그 | 정확히 10개 |
| 카테고리 | 블로그별 고정 |
| 마무리 | 자주 묻는 질문 또는 정리 문단 |
| 출처 표기 | 이미지 출처 한 줄 |

이 표를 그대로 쓰지 않아도 됩니다. 다만 숫자를 바꾸면 뒤에 나오는 검수 스크립트의 값을 함께 바꿔야 합니다. 표와 스크립트가 어긋나면 검사가 통과하는데도 실제 글이 규격을 벗어나는 상태가 됩니다.
