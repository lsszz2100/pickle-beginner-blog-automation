# 09-2. 발행 기록과 재개

## 이 절에서 하는 일

발행이 중간에 멈췄을 때 어디서부터 다시 시작할지 정하는 방법을 다룹니다. 매일 열 편씩 발행하다 보면 한 편이 실패하는 일이 반드시 생깁니다. 그때 처음부터 다시 돌리면 중복이 생깁니다.

## 상태를 남긴다는 것

"오늘 몇 편 중 몇 편을 했고, 어느 주소로 올라갔는가"를 기록해 두는 것입니다. 이 기록이 있으면 실패한 편만 골라 다시 보낼 수 있습니다.

| 기록 항목 | 쓰임 |
| --- | --- |
| 날짜 | 오늘 회차인지 확인 |
| 블로그 | 어느 사이트에 올렸는지 |
| 제목 | 중복 확인 |
| 주소 | 발행 결과 확인 |
| 상태 | 성공, 실패, 건너뜀 |

## 이렇게 말하면 됩니다

```
발행 기록을 남기고, 중간에 멈추면 이어서 하게 해 줘.
- 오늘 발행한 글의 제목과 주소, 상태를 표로 남기기
- 다시 실행할 때 이미 올라간 글은 건너뛰기
- 실패한 편만 골라서 다시 보내기
저녁에 오늘 기록을 요약해서 보여 줘.
```

## 피클이 되묻는 것

| 피클의 질문 | 내가 고르는 답 |
| --- | --- |
| 기록을 어디에 남길까요 | 작업 폴더의 표 파일 |
| 며칠 치를 보관할까요 | 30일 |
| 실패가 반복되면 알려 줄까요 | 3회 이상이면 알림 |

## 재개할 때의 순서

1. 오늘 기록을 엽니다.
2. 상태가 실패인 줄을 확인합니다.
3. 같은 제목의 글이 이미 올라갔는지 봅니다.
4. 없으면 그 편만 다시 보냅니다.
5. 있으면 건너뜀으로 바꿉니다.

## 같은 글이 두 번 올라가는 것을 막는 문장

```
다시 실행하기 전에, 같은 제목의 글이 이미 발행되었는지 먼저 확인해 줘. 있으면 새로 올리지 말고 건너뛰었다고 보고해 줘.
```

## 잘 안 될 때는 이렇게 말합니다

- "어제 글이 오늘 또 올라갔어."라고 하면 제목 기준 중복 확인을 넣습니다.
- "기록이 비어 있어."라고 하면 발행 직후 기록을 남기도록 순서를 바꿉니다.
- "실패가 매일 같은 편에서 나."라고 하면 그 원고의 이미지나 길이를 확인합니다.
