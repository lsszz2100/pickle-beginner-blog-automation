# 11-2. 중급 문제

## 문제

1. 피클이 "어느 블로그에 올릴까요"라고 물었습니다. 무엇을 알려 주면 되는가.
2. 로그인 카드가 떴는데 아이디가 기억나지 않습니다. 어떻게 말하는가.
3. 2단계 인증 알림이 5분째 오지 않습니다. 어떤 선택지가 있는가.
4. 발행은 되었는데 본문이 비어 있습니다. 원인과 요청 문장을 쓰시오.
5. 예약이 걸리지 않고 바로 공개되었습니다. 무엇을 확인하는가.
6. 같은 글이 두 번 올라갔습니다. 다시 실행할 때 무엇을 먼저 확인해야 하는가.
7. 태그가 20개씩 달립니다. 어느 규칙을 다시 정해야 하는가.
8. 카테고리가 두 개로 나뉘어 글 목록이 어수선합니다. 무엇을 하는가.
9. 애드센스에서 "가치가 낮은 콘텐츠" 판정을 받았습니다. 고치는 순서를 쓰시오.
10. ads.txt가 열리지 않습니다. 확인할 세 가지는 무엇인가.
11. 네이버 소유 확인이 계속 실패합니다. 무엇을 확인하는가.
12. 워드프레스에 글이 발행되지 않고 오류도 보이지 않습니다. 확인할 세 지점은 무엇인가.
13. 대표이미지가 목록에서 깨져 보입니다. 원인 두 가지는 무엇인가.
14. 호스팅 저장 용량이 90%입니다. 무엇부터 정리하는가.
15. 하루 발행이 10편에서 7편으로 줄었습니다. 무엇을 확인하는가.

## 정답과 해설

1. 블로그 주소나 이름. 여러 블로그를 운영한다면 시작 시각까지 함께 알려 주면 좋습니다.
2. "아이디가 기억 안 나"라고 말합니다. 피클이 계정 찾기 절차를 안내하고, 비밀번호를 새로 만들지는 사용자가 결정합니다.
3. 카카오톡에서 직접 인증하거나, 조금 기다렸다가 다시 요청합니다. 인증 코드를 다른 곳에 붙여넣지 않습니다.
4. 화면에만 글이 들어가고 저장 데이터에는 들어가지 않은 경우입니다. "본문이 비어 있으니 다시 발행해 줘"라고 요청하고, 발행 뒤 본문 길이 확인을 붙입니다.
5. 예약 시각이 과거인지 확인합니다. 과거 시각은 즉시 공개로 처리됩니다.
6. 같은 제목의 글이 이미 있는지 목록에서 확인합니다. 있으면 건너뛰고, 없으면 그 편만 다시 보냅니다.
7. 태그 수를 10개로 고정하는 규칙입니다. 태그 종류와 개수를 규격표에 다시 적습니다.
8. 이름이 같은 카테고리를 하나로 합칩니다. 자동 발행은 이름으로 찾기 때문에 중복이 있으면 갈립니다.
9. 문제 글 목록을 만들고, 살릴 글과 내릴 글을 나눈 뒤, 살릴 글을 보강하고, 필수 페이지를 채우고, 재검토를 한 번 요청합니다.
10. 파일 위치, 파일 이름의 대소문자, 내용에 게시자 ID가 들어 있는지.
11. 확인 코드가 실제 페이지에 들어갔는지, 코드를 넣은 뒤 저장했는지, 캐시 때문에 이전 화면이 보이는지.
12. 인증 상태, 사이트 상태(접속 가능 여부), 발행 기록. 세 가지 중 하나에서 멈춥니다.
13. 외부 이미지 주소가 만료되었거나, 대표이미지 크기가 규격과 다른 경우입니다.
14. 오래된 큰 이미지부터 정리합니다. 글에 쓰인 이미지는 남기고 같은 역할의 새 이미지를 줄여 교체합니다.
15. 실패 편수와 원인을 봅니다. 같은 원인이 반복되면 규격이나 이미지 문제이고, 흩어져 있으면 사이트 상태 문제입니다.
