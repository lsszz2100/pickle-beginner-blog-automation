# 10-5. 4주차: 확장과 측정

## 이 절에서 하는 일

마지막 주에는 블로그를 늘리고, 숫자를 읽고, 다음 달 계획을 세웁니다. 자동화가 돌아가는 상태에서 무엇을 키울지 정하는 주입니다.

## 요일별 할 일

| 요일 | 할 일 | 결과 |
| --- | --- | --- |
| 월 | 첫 주간 보고 받기 | 표 한 장 |
| 화 | 유입이 많은 글 다섯 개 확인 | 주제 파악 |
| 수 | 개선 두 가지 적용 | 규격 또는 제목 수정 |
| 목 | 블로그 확장 | 두 번째 블로그 연결 |
| 금 | 비용과 한도 점검 | 호스팅 사용량 |
| 토 | 다음 달 계획 | 목표 세 줄 |
| 일 | 휴식 | 없음 |

## 이렇게 말하면 됩니다

월요일:

```
지난 한 주를 정리해서 보고해 줘. 발행 편수, 색인 수 변화, 유입이 많은 글 다섯 개, 광고 수익, 제휴 클릭, 반복되는 실패 원인을 표로 알려 줘.
```

수요일:

```
보고에서 개선할 것 두 가지를 골라서 적용해 줘. 예를 들어 유입이 많은 주제로 3편 더 쓰기, 제목이 긴 글의 제목 줄이기. 무엇을 바꿨는지 알려 줘.
```

목요일:

```
두 번째 티스토리 블로그에도 같은 방식으로 발행을 붙여 줘. 시작 시각은 15분 늦게, 간격과 규격은 같게.
```

## 확장할 때 지키는 순서

1. 첫 블로그가 2주 연속 실패 없이 돌았는지 확인합니다.
2. 두 번째 블로그를 같은 규격으로 연결합니다.
3. 시작 시각만 어긋나게 둡니다.
4. 일주일 뒤 발행량과 실패 편수를 비교합니다.

## 주차 점검 문장

```
4주차 점검을 해 줘. 이번 달 발행 편수, 실패 편수, 색인 수, 수익, 제휴 클릭을 정리하고, 다음 달에 바꿀 것 세 가지만 추천해 줘. 각 추천에 기대 효과와 확인 방법을 붙여 줘.
```

## 다음 달 목표 세 줄의 예

- 하루 발행을 블로그별 10편으로 유지하고 실패율을 5% 아래로 낮춘다.
- 유입이 많은 상위 주제로 주 5편을 추가한다.
- 애드센스 승인 결과를 확인하고, 반려되면 사유별로 두 편씩 고친다.

## 잘 안 될 때는 이렇게 말합니다

- "확장했더니 실패가 늘었어."라고 하면 편수를 줄이고 원인을 먼저 봅니다.
- "다음 달 목표를 모르겠어."라고 하면 지난달 숫자에서 가장 약한 항목을 기준으로 제안받습니다.
- "수익이 거의 없어."라고 하면 색인과 유입부터 확인합니다.
