# 08-2. 제휴 고지와 운영 정책

## 이 절에서 하는 일

제휴 링크를 쓸 때 반드시 붙여야 하는 고지와, 지키지 않으면 문제가 되는 운영 규칙을 정리합니다. 이 부분은 수익보다 중요합니다. 고지가 없으면 링크가 삭제되거나 계정이 정지될 수 있습니다.

## 고지 문구

글에 제휴 링크가 있으면 독자가 알 수 있게 표시합니다. 문구는 짧고 분명하면 됩니다.

```
이 글에는 제휴 링크가 포함되어 있으며, 링크를 통한 구매 시 일정 수수료를 받을 수 있습니다.
```

위치와 형태는 다음을 지킵니다.

| 항목 | 권장 |
| --- | --- |
| 위치 | 글 상단 첫 문단 아래 또는 글 맨 아래 |
| 형태 | 본문과 같은 크기, 흐리게 처리하지 않기 |
| 개수 | 글당 한 번 |
| 자동 발행 | 규격에 넣어 매 글에 자동으로 |

## 지켜야 할 운영 규칙

| 규칙 | 내용 |
| --- | --- |
| 과장 금지 | 효과를 보장하거나 최저가라고 단정하지 않습니다 |
| 허위 정보 금지 | 쓰지 않은 제품을 써 봤다고 쓰지 않습니다 |
| 링크 남용 금지 | 글 하나에 여러 링크를 넣지 않습니다 |
| 저작권 | 상품 이미지를 그대로 쓰지 않고 직접 촬영하거나 공식 이미지를 씁니다 |
| 개인정보 | 구매자 정보나 주문 정보를 글에 쓰지 않습니다 |

## 이렇게 말하면 됩니다

```
제휴 고지 문구를 규격에 넣어서 모든 글에 자동으로 붙게 해 줘.
- 위치는 글 맨 아래, 본문과 같은 크기
- 문구는 "이 글에는 제휴 링크가 포함되어 있으며, 링크를 통한 구매 시 일정 수수료를 받을 수 있습니다."
- 고지가 빠진 글이 있으면 알려 줘
```

## 피클이 되묻는 것

| 피클의 질문 | 내가 고르는 답 |
| --- | --- |
| 고지를 맨 위에 넣을까요, 맨 아래에 넣을까요 | 맨 아래, 필요하면 첫 문단 아래에도 |
| 이미 발행한 글에도 소급해서 넣을까요 | 최근 글부터 차례로 |
| 다른 제휴도 같은 문구를 쓸까요 | 같은 문구로 통일 |

## 이미 발행한 글을 고칠 때

```
최근 30편 중에 제휴 링크가 있는데 고지가 없는 글을 찾아서, 고지 문구를 넣어 줘. 끝나면 몇 편을 고쳤는지 알려 줘.
```

## 잘 안 될 때는 이렇게 말합니다

- "고지가 두 번 들어간 글이 있어."라고 하면 중복을 정리합니다.
- "플랫폼에서 링크가 삭제됐어."라고 하면 정책 위반 사유를 확인하고 같은 실수를 막는 규칙을 추가합니다.
- "고지 문구가 너무 길어."라고 하면 한 문장으로 줄입니다.
