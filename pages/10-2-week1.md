# 10-2. 1주차: 기반 만들기

## 이 절에서 하는 일

1주차는 글이 아니라 환경을 만듭니다. 이 주에 계정과 블로그를 정리해 두면 나머지 3주가 가벼워집니다.

## 요일별 할 일

| 요일 | 할 일 | 사람이 하는 부분 |
| --- | --- | --- |
| 월 | 계정 세 개 정리 | 이메일 확인 |
| 화 | 티스토리 블로그 개설 | 주소와 이름 정하기 |
| 수 | 손으로 글 3편 쓰기 | 직접 쓰기 |
| 목 | 규격표 만들기 | 값 고르기 |
| 금 | 로그인 연결 | 카드에 아이디 입력 |
| 토 | 점검 | 결과 확인 |
| 일 | 휴식 | 없음 |

## 이렇게 말하면 됩니다

월요일:

```
블로그 자동화를 시작하려고 해. 계정 세 개(카카오, 구글, 호스팅)를 정리하는 것부터 도와줘. 지금 내가 가진 계정을 확인하고, 어느 것을 기준으로 맞추면 좋을지 알려 줘.
```

목요일:

```
내 블로그 글 규격표를 만들어 줘. 분량, 소제목, 문단, 이미지, 태그, 링크 항목으로 표를 만들고 추천 값과 이유를 붙여 줘.
```

금요일:

```
티스토리 로그인을 연결해 줘. 로그인 카드를 띄우고, 2단계 인증이 오면 알려 줘.
```

## 이번 주에 남겨야 할 것

| 결과물 | 어디에 |
| --- | --- |
| 블로그 주소 목록 | 메모 또는 작업 폴더 |
| 글 3편 | 블로그에 발행 |
| 규격표 | 작업 폴더 |
| 로그인 연결 상태 | 피클이 확인한 결과 |

## 주차 점검 문장

```
1주차 점검을 해 줘. 블로그 개설, 글 3편 발행, 규격표 저장, 로그인 연결이 모두 되었는지 확인하고 표로 알려 줘. 부족한 항목이 있으면 2주차 전에 채울 순서를 알려 줘.
```

## 잘 안 될 때는 이렇게 말합니다

- "글 3편을 못 썼어."라고 하면 1편만 쓰고 넘어가도록 조정합니다.
- "블로그를 두 곳만 할래."라고 하면 계획을 두 곳으로 줄입니다.
- "규격표 값이 마음에 안 들어."라고 하면 샘플 한 편을 써서 비교합니다.
