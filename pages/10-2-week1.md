# 10-2. 1주차: 기반 만들기

## 목표

블로그 네 곳이 열리고, 각 블로그에 글 세 편이 올라가 있으며, 규격표가 완성된 상태.

## 1일차: 계정과 블로그 개설

```text
[ ] 구글 계정으로 서치콘솔 접속 확인
[ ] 카카오 계정으로 티스토리 블로그 3개 개설
[ ] 블로그 이름과 주소 확정
[ ] 각 블로그에 카테고리 3~5개 생성
```

블로그 세 개를 한 번에 만들 때는 주소를 미리 정해 둡니다. 만들다가 생각하면 중간에 멈추고, 멈춘 채로 일주일이 지납니다.

## 2일차: 워드프레스

```text
[ ] 호스팅 신청, 도메인 연결
[ ] SSL 인증서 발급
[ ] 워드프레스 설치
[ ] 시간대 서울, 고유주소 글 이름, 검색엔진 공개 확인
[ ] 기본 글과 페이지 삭제
[ ] /wp-json/ 응답 확인
```

## 3일차: 규격표

```text
[ ] 참고할 글 하나를 골라 구조를 숫자로 센다
[ ] 분량, 섹션 수, 이미지 수, 태그 수를 정한다
[ ] spec.json 작성
[ ] 검수 스크립트에 값 반영
[ ] 검수 스크립트를 실제 글 한 편에 돌려 본다
```

검수 스크립트를 실제로 돌려 보는 것이 이날의 핵심입니다. 통과해야 할 글이 통과하지 못하면 기준이 너무 빡빡한 것이고, 통과해서는 안 될 글이 통과하면 검사가 부실한 것입니다.

## 4일차: 첫 글 세 편

```text
[ ] 블로그 A에 글 1편 직접 작성
[ ] 블로그 B에 글 1편 직접 작성
[ ] 블로그 C에 글 1편 직접 작성
[ ] 각 글에 이미지 3장, 태그 10개 넣기
[ ] 발행 후 공개 화면 확인
```

직접 쓰는 이유는 규격을 몸으로 확인하기 위해서입니다. 3,000자가 어느 정도인지, 이미지 다섯 장이 화면에서 어떻게 보이는지 한 번 겪으면, 이후 자동 생성 원고를 판단하는 눈이 생깁니다.

## 5일차: 워드프레스 첫 글

```text
[ ] 글 1편 작성 및 발행
[ ] Slim SEO 설정
[ ] 사이트맵 확인
[ ] 대표이미지 설정
```

## 6일차: 점검

```text
[ ] 네 곳 공개 화면에서 글 확인
[ ] 이미지 깨짐 없는지
[ ] 모바일에서 한 글 읽어 보기
[ ] 로그아웃 상태에서 확인
```

## 7일차: 쉬기

첫 주에 무리하면 둘째 주에 멈춥니다. 7일차는 비워 둡니다. 다만 한 가지만 합니다.

```text
[ ] 다음 주에 쓸 주제 후보 30개 적기
```

주제 후보를 미리 적어 두면, 자동 생성 단계에서 주제를 고르는 시간이 줄어듭니다.

## 1주차 체크

| 확인 | 기준 |
| --- | --- |
| 블로그 수 | 4곳 |
| 글 수 | 최소 6편 |
| 규격표 | 있음 |
| 검수 스크립트 | 동작함 |
| 애드센스 | 아직 신청하지 않음 |

애드센스는 2주차 이후에 신청합니다. 글이 여섯 편뿐인 상태로 신청하면 반려되기 쉽습니다.
