# 08-3. 클릭이 일어나는 글 구조

## 이 절에서 하는 일

링크를 넣었다고 클릭이 생기지는 않습니다. 어떤 글에서 클릭이 일어나는지 구조로 정리합니다. 이 구조를 규격에 넣으면 자동 발행 글도 클릭을 만듭니다.

## 클릭이 일어나는 다섯 자리

| 자리 | 하는 일 | 예 |
| --- | --- | --- |
| 도입 | 독자의 상황을 짚습니다 | 매달 나가는 구독료가 부담이라면 |
| 비교 | 선택지를 좁힙니다 | 세 가지 중에서 고르는 기준 |
| 경험 | 직접 써 본 결과를 적습니다 | 두 달 써 보고 남은 것 |
| 링크 | 결정한 사람에게 길을 줍니다 | 이 제품이 궁금하다면 |
| 마무리 | 다음 행동을 제안합니다 | 오늘 하나만 바꿔 보십시오 |

링크는 네 번째 자리에 둡니다. 도입에 바로 링크가 나오면 광고로 읽히고, 마무리에만 있으면 지나칩니다.

## 글 구조의 예

1. 도입: 독자가 겪는 상황 두세 문장
2. 문제: 왜 지금 이 선택이 필요한지
3. 비교: 기준 세 가지와 후보
4. 경험: 직접 확인한 내용
5. 링크: 해당 상품 하나
6. 주의: 단점이나 조건
7. 마무리: 다음 행동

단점을 적는 자리가 의외로 중요합니다. 장점만 있으면 신뢰가 떨어지고, 단점을 적으면 읽는 사람이 판단할 거리가 생깁니다.

## 이렇게 말하면 됩니다

```
제휴 글이 클릭을 만들도록 구조를 규격에 넣어 줘.
- 도입은 독자 상황 두세 문장
- 비교 기준 세 가지
- 직접 확인한 내용 한 단락
- 링크는 하나만, 비교 뒤에
- 단점이나 조건 한 단락
- 마무리는 다음 행동 한 문장
```

## 피클이 되묻는 것

| 피클의 질문 | 내가 고르는 답 |
| --- | --- |
| 경험을 어디서 가져올까요 | 직접 쓴 글과 확인한 내용에서 |
| 단점을 꼭 넣어야 하나요 | 조건과 한계를 한 단락으로 |
| 링크 위치를 바꿀까요 | 비교 뒤 한 곳만 |

## 확인하는 지표

| 지표 | 뜻 | 개선 방향 |
| --- | --- | --- |
| 클릭률 | 글 조회 대비 링크 클릭 | 링크 위치와 문장 |
| 체류 시간 | 글에 머문 시간 | 도입과 구조 |
| 이탈률 | 첫 화면에서 나간 비율 | 도입 문장 |

## 잘 안 될 때는 이렇게 말합니다

- "조회는 있는데 클릭이 없어."라고 하면 링크 문장과 위치를 바꿉니다.
- "클릭은 있는데 구매가 없어."라고 하면 상품과 글 주제가 맞는지 확인합니다.
- "글이 광고 같다는 댓글이 달려."라고 하면 경험과 단점 비중을 늘립니다.
