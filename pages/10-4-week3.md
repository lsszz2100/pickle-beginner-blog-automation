# 10-4. 3주차: 검색과 수익

## 목표

사이트 네 곳이 모두 검색엔진에 등록되고, 애드센스 검토가 요청된 상태.

## 15일차: 구글 서치콘솔

```text
[ ] 도메인 또는 URL 접두어 속성 추가
[ ] 소유 확인 (티스토리: 메타 태그, 워드프레스: 플러그인)
[ ] 사이트맵 제출
[ ] 색인 생성 > 페이지 화면 확인
```text

## 16일차: 네이버 서치어드바이저

```text
[ ] 사이트 추가
[ ] HTML 태그 소유 확인
[ ] RSS 제출
[ ] 사이트맵 제출 (캡차는 직접)
```text

## 17일차: 다음 검색등록

```text
[ ] 티스토리는 등록이 필요한지 먼저 확인
[ ] 워드프레스만 등록 신청
[ ] 사이트 응답이 200인지 확인 후 신청
```text

## 18일차: 애드센스 사전 점검

| 확인 | 기준 |
| --- | --- |
| 글 수 | 스무 편 이상 |
| 최소 분량 | 1,500자 이상 |
| 정책 페이지 | 3개 |
| 이미지 | 깨진 것 없음 |
| 사이트 속도 | 모바일에서 3초 이내 |

정책 페이지 세 개는 새로 만들어야 합니다. 개인정보처리방침, 소개, 문의입니다. 글 목록과 분리된 메뉴에 둡니다.

## 19일차: 애드센스 사이트 추가

```text
[ ] 사이트 추가
[ ] ads.txt 설정
[ ] 소유 확인
[ ] 광고 코드 삽입 확인
```text

## 20일차: 검토 요청

```text
[ ] 사이트를 로그아웃 상태에서 확인
[ ] 정책 페이지 접근 확인
[ ] 검토 요청
[ ] 요청 후 큰 변경 금지
```text

## 21일차: 상태 확인과 기록

```text
[ ] 사이트 상태 문구 확인
[ ] 서치콘솔 색인 수 확인
[ ] 서치어드바이저 노출 확인
[ ] 표에 기록
```text

## 3주차 체크

| 확인 | 기준 |
| --- | --- |
| 검색 등록 | 4곳 |
| 사이트맵 | 제출됨 |
| 애드센스 | 요청 또는 승인 |
| 색인 | 발행의 30퍼센트 이상 |

## 승인이 늦어질 때

검토는 며칠에서 몇 주 걸립니다. 이 기간에 할 일은 두 가지입니다.

1. 발행을 계속한다. 글 수가 늘면 검토에 유리합니다.
2. 품질을 올린다. 얕은 글을 보강합니다.

하지 말아야 할 일은 세 가지입니다. 요청 반복, 사이트 구조 변경, 글 대량 삭제. 세 가지 모두 검토자가 보는 상태를 흐트러뜨립니다.

## 3주차에 자주 나오는 문구

| 문구 | 의미 | 다음 주에 할 일 |
| --- | --- | --- |
| 준비 중 | 검토 대기 | 그대로 대기 |
| 주의 필요 - 가치가 별로 없는 콘텐츠 | 품질 문제 | 중복 정리, 보강 |
| 주의 필요 - 정책 위반 | 정책 문제 | 해당 페이지 수정 |
| 준비됨 | 승인 | 광고 배치 확인 |

두 번째 문구가 나오면 4주차 계획을 바꿉니다. 새 글을 늘리는 대신 기존 글을 고칩니다.
