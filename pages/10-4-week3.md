# 10-4. 3주차: 수익화

## 이 절에서 하는 일

3주차에는 광고와 제휴를 붙입니다. 글은 이미 돌고 있으므로, 이 주는 수익 구조를 만드는 데 씁니다.

## 요일별 할 일

| 요일 | 할 일 | 사람이 하는 부분 |
| --- | --- | --- |
| 월 | 애드센스 신청 | 신청서와 결제 정보 입력 |
| 화 | 검색엔진 등록 | 보안문자 입력 |
| 수 | 쿠팡파트너스 가입 | 가입 정보 입력 |
| 목 | 고지 규칙 적용 | 문구 확인 |
| 금 | 링크 배치 | 어떤 글에 어떤 상품인지 결정 |
| 토 | 점검 | 표 확인 |
| 일 | 휴식 | 없음 |

## 이렇게 말하면 됩니다

월요일:

```
애드센스 신청 전에 사이트를 점검해 줘. 글 수, 필수 페이지, 사이트 상태를 확인하고 부족한 항목을 알려 줘. 문제가 없으면 신청 화면까지 열어 줘.
```

화요일:

```
구글, 네이버, 다음에 사이트를 등록해 줘. 보안문자가 나오면 화면을 넘겨 줘. 끝나면 등록 상태와 사이트맵 제출 결과를 표로 알려 줘.
```

금요일:

```
제휴 링크를 글에 붙여 줘. 글 하나당 하나, 쿠팡과 다른 제휴를 번갈아. 고지 문구는 모든 글에 자동으로 들어가게 하고, 빠진 글이 있으면 알려 줘.
```

## 3주차에 결정해야 할 것

| 결정 | 선택지 | 기준 |
| --- | --- | --- |
| 광고 위치 | 본문 중간, 하단 | 읽기를 방해하지 않는 쪽 |
| 링크 비중 | 글당 1개 | 신뢰가 우선 |
| 신청 순서 | 준비된 사이트부터 | 한 곳씩 |

## 주차 점검 문장

```
3주차 점검을 해 줘. 애드센스 신청 상태, 검색엔진 등록 상태, 제휴 링크와 고지 문구가 모든 글에 들어갔는지 확인해서 표로 알려 줘. 반려된 항목이 있으면 이유와 다음 순서를 알려 줘.
```

## 잘 안 될 때는 이렇게 말합니다

- "애드센스에서 반려됐어."라고 하면 사유를 읽고 고칠 순서를 정합니다.
- "제휴 링크를 어디에 넣을지 모르겠어."라고 하면 검색 유입이 있는 글부터 제안받습니다.
- "광고가 너무 많아 보여."라고 하면 광고 수를 줄입니다.
