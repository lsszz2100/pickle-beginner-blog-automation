# 00-2. 준비물과 읽는 순서

## 준비물

| 항목 | 필요한 이유 | 없으면 |
| --- | --- | --- |
| 구글 계정 | 애드센스, 서치콘솔, 워드프레스 분석 | 진행 불가 |
| 카카오 계정 | 티스토리 개설 | 진행 불가 |
| 피클 | 원고 생성과 발행 작업 위임 | 손으로 하거나 다른 도구로 대체 |
| 도메인 + 호스팅 | 워드프레스 운영 | 티스토리만 운영 |
| 이미지 편집 도구 | 대표이미지 압축, 화면 가림 | 웹 도구로 대체 |

호스팅은 처음부터 필요하지 않습니다. 티스토리만으로 01장부터 04장까지, 06장의 절반까지 진행할 수 있습니다. 워드프레스를 붙이는 시점은 05장입니다.

## 읽는 순서

이 책은 세 가지 경로로 읽을 수 있습니다.

| 경로 | 순서 | 걸리는 시간 |
| --- | --- | --- |
| 정석 | 00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 | 3~4주 |
| 빠른 실행 | 00 → 02 → 03 → 04 → 07 → 06 | 1주 |
| 수익화 우선 | 00 → 01 → 06 → 07 → 08 → 03 → 04 | 2주 |

처음이라면 정석 경로를 권합니다. 03장의 규격이 없으면 04장과 05장에서 만든 절차가 매번 다른 결과를 냅니다. 순서를 건너뛰면 나중에 두 배로 돌아와야 합니다.

## 실습 환경에 대한 두 가지 주의

첫째, 이 책의 화면 그림은 2026년 11월 기준입니다. 서비스 화면은 예고 없이 바뀝니다. 그림과 실제 화면이 다르면 버튼 이름과 위치를 기준으로 찾으십시오. 그림에 찍힌 주소와 이름은 모두 바꿔 두었습니다.

둘째, 실습은 되도록 새 블로그에서 하십시오. 기존 블로그에 자동 발행을 붙이면 중복 글이 쌓이고, 잘못된 설정이 남은 글에까지 적용됩니다. 실습용 블로그 하나를 따로 만들고, 절차가 안정된 뒤 옮기는 편이 안전합니다.
