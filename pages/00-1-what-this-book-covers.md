# 00-1. 이 책이 다루는 것

이 책은 블로그 운영을 자동화하는 실습서입니다. 정확히는 다음 네 가지를 만듭니다.

1. 발행할 글의 규격표와 검수 절차
2. 티스토리 블로그에 글을 넣는 절차
3. 워드프레스에 예약 발행까지 처리하는 스크립트
4. 발행한 글이 검색에 실리고 광고가 붙는 상태를 확인하는 점검표

이 네 가지가 갖춰지면, 하루에 몇 편을 쓰든 사람이 개입하는 지점은 "오늘 무엇을 쓸지 고르는 일"과 "결과를 확인하는 일" 두 가지로 줄어듭니다.

## 대상 독자

| 독자 | 이 책에서 얻는 것 |
| --- | --- |
| 블로그를 한두 개 운영 중인 사람 | 손으로 하던 반복 작업을 절차로 바꾸는 방법 |
| 애드센스 승인을 기다리는 사람 | 승인 전에 갖춰야 할 페이지와 글의 조건 |
| 강의나 강의자료를 만드는 사람 | 실습 과제로 바로 쓸 수 있는 예제와 예상문제 |
| 피클을 막 시작한 사람 | 말로 일을 맡기고 결과를 검수하는 방식 |

## 다루지 않는 것

- 특정 서비스의 내부 구조나 운영 원리. 이 책은 독자가 화면에서 보고 판단할 수 있는 것만 다룹니다.
- 계정 아이디, 비밀번호, 사이트 주소, 결제 정보. 예시는 모두 `blog-a.tistory.com`, `mysite.mycafe24.com` 같은 자리표시자입니다.
- 저작권이 있는 이미지와 글을 가져다 쓰는 방법. 이 책은 상업적 이용이 허용된 자료만 씁니다.
- 검색 순위를 빠르게 올리는 요령. 대신 색인 상태를 읽고 원인을 고치는 절차를 다룹니다.

## 필요한 사전 지식

HTML 태그를 읽을 수 있으면 충분합니다. `<h1>`, `<p>`, `<img>`가 무엇인지 알고, 표를 보고, 터미널에 명령 한 줄을 붙여 넣을 수 있으면 끝까지 따라올 수 있습니다. 코드를 새로 작성하는 일은 거의 없습니다. 이 책의 코드는 대부분 붙여 넣고 값만 바꾸는 형태입니다.
