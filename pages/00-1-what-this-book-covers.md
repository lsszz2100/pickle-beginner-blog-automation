# 00-1. 이 책이 다루는 것

이 책은 블로그 운영을 피클에게 맡기는 실습서입니다. 코드를 짜는 책이 아닙니다. 대화창에 문장을 넣고, 피클이 띄우는 카드에 답하고, 결과를 확인하는 일을 매일 반복할 수 있는 형태로 만듭니다.

정확히는 다음 네 가지를 만듭니다.

1. 발행할 글의 규격표와 발행 전 검수 문장
2. 티스토리에 매일 자동으로 글이 올라가는 루틴
3. 워드프레스에 예약 발행까지 맡기는 루틴
4. 발행한 글이 검색에 실리고 광고가 붙는 상태를 확인하는 점검표

이 네 가지가 갖춰지면 사람이 개입하는 지점은 "오늘 무엇을 쓸지 고르는 일"과 "결과를 확인하는 일" 두 가지로 줄어듭니다.

## 대상 독자

| 독자 | 이 책에서 얻는 것 |
| --- | --- |
| 블로그를 한두 개 운영 중인 사람 | 손으로 하던 반복 작업을 말로 맡기는 방법 |
| 애드센스 승인을 기다리는 사람 | 승인 전에 갖춰야 할 페이지와 글의 조건 |
| 강의나 강의자료를 만드는 사람 | 실습 과제로 바로 쓸 수 있는 예제와 예상문제 |
| 피클을 막 시작한 사람 | 말로 일을 맡기고 결과를 확인하는 방식 |

## 이 책의 방식

각 절은 같은 순서로 되어 있습니다. 먼저 피클에게 그대로 붙여넣을 문장을 보여 주고, 피클이 무엇을 되묻는지 표로 정리하고, 사용자가 직접 할 일을 적고, 끝나면 어떤 화면이 보이는지 그림으로 보여 줍니다. 마지막에는 잘 안 될 때 쓸 문장을 붙였습니다.

그래서 읽는 방법도 단순합니다. 문장을 복사해 보내고, 되묻는 것에 답하고, 그림과 결과를 비교하면 됩니다.

## 다루지 않는 것

- 특정 서비스의 내부 구조나 운영 원리. 이 책은 독자가 화면에서 보고 판단할 수 있는 것만 다룹니다.
- 계정 아이디, 비밀번호, 사이트 주소, 결제 정보. 예시는 모두 `blog-a.tistory.com`, `blog.example.com` 같은 자리표시자입니다.
- 저작권이 있는 이미지와 글을 가져다 쓰는 방법. 이 책은 상업적 이용이 허용된 자료만 씁니다.
- 검색 순위를 빠르게 올리는 요령. 대신 색인 상태를 읽고 원인을 고치는 절차를 다룹니다.

## 필요한 사전 지식

없습니다. 블로그에 글을 한 번이라도 올려 본 경험이면 충분합니다. 코드는 03장과 05장의 참고 절에만 조금 나오고, 그마저도 몰라도 진행할 수 있게 썼습니다.

비밀번호를 카드에 입력하는 일, 휴대폰 알림을 승인하는 일, 결과 표를 읽는 일은 사람이 해야 합니다. 이 세 가지를 제외하면 나머지는 피클에게 말로 시킬 수 있습니다.
