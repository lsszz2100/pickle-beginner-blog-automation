# 12-1. 부록: 지시문과 체크리스트

## 지시문 템플릿

자동화를 맡길 때 매번 같은 실수를 반복하지 않으려면 지시문에 네 가지를 넣습니다.

| 항목 | 내용 |
| --- | --- |
| 목표 | 무엇을 만들지 한 문장 |
| 조건 | 분량, 이미지 수, 태그 수, 금지 표현 |
| 금지 | 계정 생성, 결제, 삭제 등 하지 말아야 할 일 |
| 확인 | 끝났는지 무엇으로 확인할지 |

### 원고 생성

```text
목표: 아래 주제로 블로그 글 한 편의 HTML 본문을 만든다.
조건: 공백 포함 3,000~5,000자, h1 5~7개, 이미지 3~7장,
      태그 10개, 자주 묻는 질문 포함, 이미지 출처 한 줄.
      제목에 과장 표현 금지, 이모지 금지.
금지: 사실 확인이 필요한 수치를 임의로 만들지 말 것.
확인: 글자 수와 태그 수를 함께 보고할 것.
```

### 발행

```text
목표: 아래 원고를 티스토리 블로그에 공개 발행한다.
조건: 카테고리 고정, 홈주제는 글 내용과 일치, 대표이미지 200KB 이하.
금지: 카테고리를 새로 만들지 말 것. 예약 시각을 과거로 두지 말 것.
확인: RSS와 공개 화면에서 제목, 시각, 대표이미지를 확인해 보고할 것.
```

### 점검

```text
목표: 아래 사이트의 지난주 상태를 표로 정리한다.
조건: 발행 성공률, 색인 수, 검색 유입, 광고 노출, 디스크 사용량.
금지: 설정을 바꾸지 말 것. 읽기만 할 것.
확인: 지난주와 비교해 나빠진 항목을 표시할 것.
```

## 규격표

```text
[ ] 분량 3,000~5,000자
[ ] h1 5~7개, h2 소제목
[ ] 이미지 3~7장, 대표이미지 1장
[ ] 태그 10개
[ ] 카테고리 고정
[ ] 자주 묻는 질문 포함
[ ] 이미지 출처 한 줄
[ ] 금지 표현 없음
```

## 발행 전 체크리스트

```text
[ ] 검수 스크립트 통과
[ ] 제목과 원고 일치
[ ] 공개 상태 확인
[ ] 대표이미지 업로드 완료
[ ] 태그 10개, 철자 확인
[ ] 예약 시각이 현재+40분 이후
```

## 주간 점검표

```text
[ ] 발행 성공률
[ ] 검수 실패 건수
[ ] 색인 증가
[ ] 광고 노출과 클릭
[ ] 디스크·트래픽
[ ] 죽은 링크
```

## 사고 대응 순서

```text
1. 사이트가 응답하는가 (200 확인)
2. 발행을 멈춘다
3. 상태 파일에 현재 상태를 남긴다
4. 원인을 하나씩 지운다
5. 재실행하고 중복이 없는지 확인한다
```

## 마지막으로 남기는 표

| 파일 | 역할 |
| --- | --- |
| `spec.json` | 규격 값 |
| `check_post.py` | 검수 |
| `publish_batch.py` | 워드프레스 발행 |
| `state.json` | 진행 상태 |
| `weekly.md` | 주간 점검 기록 |

이 다섯 파일이 이 책의 결과물입니다. 내용은 짧지만, 매일 이것들이 돌아가면 블로그는 멈추지 않습니다.
