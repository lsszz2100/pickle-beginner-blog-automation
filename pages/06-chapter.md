# 06. 애드센스 승인과 운영

애드센스 승인은 두 번 걸립니다. 처음에는 사이트 검토에서, 다음에는 콘텐츠 품질에서. 이 장은 두 관문을 각각 다룹니다.

승인 전에 알아 둘 사실이 있습니다. 승인은 수익의 시작이 아니라 관문입니다. 승인을 받아도 유입이 없으면 수익은 0에 가깝습니다. 실제로 승인 후 한 달간의 수익이 0.01달러 수준인 경우도 있습니다. 승인에 매달리기보다 승인 후 운영이 오래가도록 만드는 편이 낫습니다.

| 단계 | 확인되는 것 |
| --- | --- |
| 사이트 추가 | 소유권, ads.txt, 정책 페이지 |
| 검토 요청 | 콘텐츠 품질, 사이트 구조 |
| 승인 | 광고 게재 시작 |
| 운영 | 노출, 클릭, 수익 |

이 장이 끝나면 사이트 상태 화면에 뜨는 문구를 읽고 무엇을 고쳐야 하는지 판단할 수 있게 됩니다.
