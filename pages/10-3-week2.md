# 10-3. 2주차: 발행 자동화

## 이 절에서 하는 일

2주차에는 실제 발행을 자동으로 돌립니다. 이 주가 이 책의 중심입니다. 하루 10편이 예약대로 올라가고, 실패한 편이 표로 보고되면 성공입니다.

## 요일별 할 일

| 요일 | 할 일 | 확인 |
| --- | --- | --- |
| 월 | 한 편 시험 발행 | 본문이 비어 있지 않은지 |
| 화 | 예약 발행 시험 | 예약 시각대로 올라가는지 |
| 수 | 10편 발행 | 간격이 벌어졌는지 |
| 목 | 실패 대응 연습 | 실패 편만 다시 보내기 |
| 금 | 자동 루틴 등록 | 정해진 시각에 시작하는지 |
| 토 | 점검 | 하루치 표 확인 |
| 일 | 휴식 | 없음 |

## 이렇게 말하면 됩니다

월요일:

```
티스토리 블로그 한 곳에 글 한 편만 시험 발행해 줘. 발행 전에 규격을 검수하고, 발행 뒤에 본문 길이와 공개 상태를 확인해서 알려 줘.
```

수요일:

```
오늘 10편을 발행해 줘. 첫 편은 지금 공개, 나머지 9편은 40~120분 간격으로 예약. 발행이 끝나면 글 목록 링크와 함께 표로 보고해 줘.
```

금요일:

```
매일 아침 7시 15분에 자동으로 돌게 등록해 줘. 오늘 결과를 한 번 더 확인하고, 실패한 편이 있으면 이유와 함께 알려 줘.
```

## 2주차에 자주 만나는 문제

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 본문이 비어 발행됨 | 화면 입력 경로 문제 | 다시 발행 요청 |
| 예약이 안 걸림 | 시각이 과거 | 미래 시각으로 재설정 |
| 글이 두 번 올라감 | 재실행 시 중복 확인 누락 | 목록 확인 후 하나 삭제 |
| 중간에 멈춤 | 한 번에 너무 많이 처리 | 편수를 나눠 요청 |

## 주차 점검 문장

```
2주차 점검을 해 줘. 하루 10편이 자동으로 올라가는지, 예약 간격이 40~120분으로 유지되는지, 실패한 편이 있는지 확인해서 표로 알려 줘. 다음 주에 넘어가도 되는지도 판단해서 알려 줘.
```

## 잘 안 될 때는 이렇게 말합니다

- "10편은 너무 많아."라고 하면 3편으로 줄여 루틴을 다시 등록합니다.
- "자동 루틴이 안 돌아."라고 하면 등록 여부와 실행 기록을 확인합니다.
- "실패가 매일 반복돼."라고 하면 원고와 이미지 규격을 먼저 점검합니다.
