# 04. 티스토리 자동 발행

티스토리는 국내 검색 노출이 빠른 대신, 발행 자동화가 가장 까다로운 플랫폼입니다. 이유는 단순합니다. 에디터가 브라우저 자동화를 막도록 만들어져 있기 때문입니다.

이 장은 "왜 안 되는지"를 먼저 정리하고, 그다음 실제로 되는 절차를 순서대로 적습니다. 세 가지 방법을 차례로 시도해 실패한 뒤에야 확정된 절차이므로, 같은 시행착오를 반복하지 않아도 됩니다.

| 시도 | 결과 |
| --- | --- |
| 스크립트로 본문 주입 | 화면에는 보이나 발행 데이터에 반영되지 않아 빈 본문이 발행됨 |
| 기본 모드에 직접 타이핑 | 타이핑할 때마다 커서가 본문 중앙으로 튀어 문단이 깨짐 |
| HTML 소스창에 글자 입력 | 소스 편집기가 입력을 차단함 |
| HTML 소스창에 붙여넣기 | 성공 |

핵심은 마지막 한 줄입니다. 사람이 붙여넣는 것과 같은 방식으로만 본문이 저장됩니다. 그래서 자동화는 "붙여넣기를 대신하는 일"이 됩니다.

이 장을 마치면 다음을 할 수 있습니다.

- 원고 HTML을 티스토리에 넣고 공개 발행까지 마치는 절차
- 예약 발행 간격을 계산해 거부당하지 않게 거는 방법
- 발행 결과를 RSS와 공개 화면에서 확인하는 방법
