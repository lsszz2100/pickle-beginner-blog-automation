# 11-3. 실무 문제와 해설

실무 문제는 정답이 하나가 아닙니다. 판단의 근거를 쓰는 것이 목적입니다.

## 문제

1. 하루 열 편을 사흘 발행한 뒤, 워드프레스 사이트가 503을 돌려주기 시작했습니다. 오늘 남은 일곱 편은 어떻게 처리하시겠습니까.
2. 발행 성공률이 70퍼센트로 떨어졌습니다. 로그에는 "이미지 2장"이 다섯 건, "응답이 JSON 아님"이 두 건 있습니다. 무엇부터 고치시겠습니까.
3. 애드센스 승인 후 첫 달 수익이 0.02달러였습니다. 다음 달에 무엇을 바꾸시겠습니까.
4. 같은 주제의 글이 사흘 간격으로 두 번 발행되었습니다. 원인을 찾고 재발을 막는 절차를 설계하십시오.
5. 사이트 색인 수가 이번 주에 20퍼센트 줄었습니다. 확인 순서를 쓰시오.
6. 티스토리 발행이 열 번 중 세 번 실패합니다. 실패한 회차만 다시 돌리는 절차를 설계하십시오.
7. 호스팅 디스크가 한도의 90퍼센트입니다. 새 이미지를 계속 업로드해야 하는 상황에서 선택지를 두 가지 제시하시오.
8. 제휴 링크를 넣은 글 스무 편 중 다섯 편의 상품이 판매 종료되었습니다. 어떻게 처리하시겠습니까.
9. 하루 마흔 편을 돌리다 보니 글의 도입 문장이 모두 비슷해졌습니다. 어떤 규칙을 추가하시겠습니까.
10. 발행 전 검수를 통과했는데 발행된 글의 태그가 아홉 개였습니다. 어느 단계를 의심하시겠습니까.

## 해설

1. 발행을 멈추고 사이트 복구를 먼저 합니다. 503 상태에서 발행을 시도하면 아무것도 만들어지지 않고, 예약 시각만 지나갑니다. 복구 후 남은 편수를 다음 회차로 넘기고, 상태 파일에 실패로 남깁니다. 판단 근거는 "사이트가 응답하지 않을 때의 발행은 결과를 남기지 않는다"입니다.

2. 이미지 문제부터 고칩니다. 다섯 건이 같은 원인이므로 한 번의 수정으로 해결됩니다. 응답 문제는 사이트 상태에 달려 있어 시간이 필요합니다. 원인이 많은 항목, 수정이 한 번으로 끝나는 항목을 먼저 처리합니다.

3. 수익이 아니라 유입을 봅니다. 수익 0.02달러는 유입이 없다는 뜻입니다. 색인 수, 검색 유입 검색어, 페이지 RPM을 확인하고, 유입이 있다면 글의 첫 화면과 광고 위치를, 없다면 색인과 주제를 고칩니다.

4. 발행 이력을 확인하지 않은 것이 원인입니다. 발행 전에 최근 30일 제목 목록을 읽고, 핵심어가 두 개 이상 겹치면 주제를 바꾸는 규칙을 넣습니다. 상태 파일에 제목을 함께 남기면 확인이 한 번의 조회로 끝납니다.

5. 제출 수 → 색인 수 → 제외 사유 → 사이트 응답 순으로 봅니다. 제출 수가 그대로인데 색인만 줄면 품질 문제이고, 제출 수도 줄었으면 사이트맵이나 발행 중단이 원인입니다.

6. 발행 전에 이미 올라간 글의 주소 목록을 확인하고, 같은 글은 건너뜁니다. 실패한 항목은 발행 기록에 남기고, 다음 회차에는 성공한 편을 빼고 남은 편만 처리합니다. 같은 회차를 통째로 다시 돌리지 않습니다.

7. 첫째, 새 이미지를 외부 링크로 바꾸고 업로드는 대표이미지로 한정합니다. 둘째, 오래된 이미지를 압축해 교체합니다. 요금제 상향은 세 번째 선택지로 둡니다. 비용이 먼저 늘면 수익 전에 부담이 됩니다.

8. 해당 링크를 같은 카테고리의 판매 중인 상품으로 바꾸거나, 링크를 제거하고 글을 정보 글로 정리합니다. 죽은 링크를 그대로 두면 신뢰가 떨어지고, 글의 검색 순위에도 불리합니다.

9. 도입 유형을 다섯 가지로 나누어 순환시키고, 첫 문장의 길이와 시작 어구를 기록해 중복을 검사합니다. 검수 항목에 "최근 20편과 첫 문장이 비슷하면 경고"를 넣는 방법도 있습니다.

10. 태그를 입력하는 단계입니다. 검수는 원고에 적힌 태그 수를 세고, 실제 입력은 발행 단계에서 이루어집니다. 중복 제거, 쪼개짐, 입력 누락을 확인하고, 발행 뒤에 태그 목록을 다시 읽어 확인하는 단계를 넣습니다.
