# 05. 워드프레스 자동 발행

티스토리에서 고생한 일을 워드프레스에서는 반복하지 않아도 됩니다. 워드프레스는 공식 REST API를 열어 두었고, 인증만 준비하면 브라우저 없이 글을 만들 수 있습니다. 예약 발행, 카테고리, 태그, 대표이미지까지 모두 API로 처리됩니다.

| 항목 | 티스토리 | 워드프레스 |
| --- | --- | --- |
| 발행 방식 | 브라우저 입력 | REST API |
| 안정성 | 화면 변화에 취약 | 안정적 |
| 예약 | 지원 | 지원 |
| 재실행 | 처음부터 다시 | 같은 글은 건너뜀 |
| 실패 지점 | 붙여넣기, 패널 입력 | 인증, 서버 차단 |

이 장의 결과물은 스크립트 두 개입니다. 하나는 원고를 검사하는 것(03-5에서 만들었습니다), 다른 하나는 발행하는 것입니다. 발행 스크립트는 여덟 단계로 나뉘고, 각 단계가 실패하면 그 지점에서 멈춥니다. 절반만 발행된 배치는 다음 실행에서 이어받습니다.

## 준비 상태 확인

시작하기 전에 세 가지를 확인합니다.

- `https://내도메인/wp-json/`이 JSON을 준다
- 관리자 계정으로 로그인된다
- 애플리케이션 비밀번호를 발급할 수 있다

세 번째가 막혀 있으면 서버 설정을 봐야 합니다. 일부 호스팅은 보안 설정으로 인증 헤더를 제거합니다.
