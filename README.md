# 피클 초급자 자동화 프로젝트: 블로그 편

블로그를 하나 열어 글을 쓰는 일에서 시작해, 매일 정해진 시각에 원고가 만들어지고 발행되고 검색에 등록되는 것까지 피클에게 말로 맡기는 실습서입니다. 코드를 짜지 않습니다. 대화창에 문장을 넣고, 피클이 띄우는 카드에 답하고, 결과를 확인하는 일을 매일 반복할 수 있는 형태로 만듭니다.

티스토리 세 곳과 워드프레스 한 곳을 동시에 굴리는 구성을 기준으로 하되, 한 곳만 운영하려는 독자도 그대로 따라올 수 있게 썼습니다.

## 어떤 독자를 위한 책인가

- 글은 써 봤지만 블로그를 운영 체계로 만드는 데서 멈춘 사람
- 자동화 도구를 설치하는 것보다, 무엇을 자동으로 돌리고 무엇을 사람이 판단할지 정하는 데 관심이 있는 사람
- 애드센스 승인과 검색 등록에서 여러 번 실패한 뒤 원인을 정리하고 싶은 사람
- 피클(Pickle)을 처음 쓰기 시작해, 말로 지시해 일을 맡기는 방식을 익히려는 사람

## 읽는 방법

각 절은 같은 순서로 되어 있습니다.

1. 그대로 붙여넣을 수 있는 프롬프트
2. 피클이 되묻는 것과 내가 고르는 답
3. 내가 직접 하는 일
4. 끝나면 보이는 실제 화면
5. 잘 안 될 때 쓰는 문장

기술적인 배경은 각 장 끝의 참고 절에 모아 두었습니다. 급하면 건너뛰어도 진행에 지장이 없습니다.
